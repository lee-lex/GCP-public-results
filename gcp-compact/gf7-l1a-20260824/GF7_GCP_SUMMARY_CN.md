# GF-7 L1A 超低存储 GCP 几何定位验证

## 结论边界

本轮从 9 幅高分辨率参考瓦片重新生成 180 个完整 256×256 GCP；Overture 只过滤中心，未修改任何 patch 像素。独立 raw/gradient/edge/feature 共识得到 124 个可用 GF-7 像点真值，其余样本保留为拒绝项。

这里的 ICP 精度以独立影像匹配真值为参照。由于 ESRI 参考影像自身缺少可核验的测量级绝对精度声明，本报告不把它写成绝对大地测量精度。

## 必答问题

1. 原始 GCP 强基线（Scharr NCC）在 GF-7 L1A 上的 ≤2 px 成功率为 **90.3%**。
2. 64 B / 128 B / 256 B 分别为 **9.7% / 0.0% / 22.6%**。
3. 单尺度 128 B DCT-sign 的跨传感器 ≤5 px 为 **16.1%**，四尺度固定 128 B 为 **9.7%**；是否足以替代传统 chip 由实测值判断，而非同传感器结果外推。
4. 当前 256 B 幅值+方向空间码在三种 compact 表示中 ≤2 px 表现最好。
5. Raw 与 128 B 的整数 RMSE 相差 **239.895 px**。
6. 仿射 RANSAC 后，128 B / 256 B 的可靠 GCP 比例为 **25.0% / 54.8%**。
7. 原始 RPC 的独立 ICP 中位 RMSE 与不同表示校正后的结果见 `icp_results.csv` 和图 05。
8. 128 B 的独立 ICP 中位 RMSE 为 **7.317 m**。
9. 128 B 相比 64 KB 是 **512×** 存储下降；相对 Raw 的 ICP RMSE 变化为 **+5.766 m**。
10. 每种表示的真实 payload 字节数和 SHA-256 均记录在 `reference_encoding_manifest.csv`。
11. 失败来源通过 raw、64 B、128 B、256 B 并排案例区分；尺度与旋转已由原始 RPC 局部雅可比归一化，未使用 GT。
12. compact 表示能否替代传统 GCP chip，必须同时满足单点复用、RANSAC GVR 与独立 ICP 三层指标；本报告保留所有负结果。

## 可复现性

- 参考表示在 target 循环前只编码一次；匹配时从冻结 payload 载入。
- 64/128/256 B 的 GF-7 候选直接编码并比较，不恢复参考图像。
- GT 不参与搜索域缩小、方法参数选择或候选评分。
- RANSAC 仅在所有单点匹配完成后运行。

## 尺度、旋转与高程消融

- 固定 256 像素窗的 ≤2 px 成功率：**0.0%**。
- RPC 完整局部仿射归一化：**86.7%**。
- RPC 后按匹配分数选择有限残差尺度/旋转：**86.7%**；选择过程不使用 GT。
- 当前 Z 的原始 RPC 中位误差：**5.451 m**；Z-50 m / Z+50 m 分别为 **6.785 / 7.494 m**。
